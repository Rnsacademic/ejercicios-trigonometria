Práctica Integradora: Trigonometría y Pitágoras

¿Cómo saber qué fórmula utilizar?

Aplica este algoritmo de decisión según los datos que te entregue el problema (en un triángulo rectángulo):

1. Regla de Oro: Datos conocidos vs. Dato buscado

  • Usa PITÁGORAS si: El problema solo involucra lados (conoces 2 lados y buscas el 3º) y NO se mencionan ángulos agudos.
  • Usa RAZONES TRIGONOMÉTRICAS si: El problema involucra al menos UN ÁNGULO agudo (ya sea como dato o como la incógnita a buscar).

2. Mnemotecnia: SOH - CAH - TOA

Identifica primero respecto al ángulo $\theta$ en cuestión cuál es el Cateto Opuesto (CO), el Cateto Adyacente (CA) y la Hipotenusa (H):

  • SOH: $\sin(\theta) = \frac{\text{Cateto Opuesto}}{\text{Hipotenusa}}$ → Usa SENO cuando relaciones Opuesto e Hipotenusa.
  • CAH: $\cos(\theta) = \frac{\text{Cateto Adyacente}}{\text{Hipotenusa}}$ → Usa COSENO cuando relaciones Adyacente e Hipotenusa.
  • TOA: $\tan(\theta) = \frac{\text{Cateto Opuesto}}{\text{Cateto Adyacente}}$ → Usa TANGENTE cuando relaciones ambos Catetos (sin la Hipotenusa).

3. Teorema de Pitágoras

Fórmula principal: c² = a² + b² (donde $c$ es la Hipotenusa)

  • Para hallar la Hipotenusa: c = √(a² + b²)
  • Para hallar un Cateto: a = √(c² - b²)
